# 可旋转冷链装箱与不可拆箱运输装载

Python 3.11 实现，仅依赖标准库（`sqlite3`、`hashlib`、`json` …），测试用 `pytest`。
仓库把商品装进保温箱后**封箱**，承运端运输的是封好的箱子本身，绝不把商品
重新当散件计算容量。

## 范围

* 8 件商品、3 种箱型、6 个封箱、4 个车辆班次（演示与测试数据集即此规模）。
* 单层二维摆放，商品可旋转 90°，坐标为非负整数；矩形边界可接触、内部不重叠；
  能否装下由**精确几何搜索**判定，绝不只凭总面积。
* 不做三维堆叠、真实道路网络、温度传感器积分。

## 模块

| 模块 | 职责 |
|---|---|
| `coldchain/geometry.py` | 精确二维摆放（DFS 枚举整数坐标 + 旋转），规范坐标放置 |
| `coldchain/packing.py` | 装箱优化器（可被包装工独立调用的纯函数）+ 规范化定序 |
| `coldchain/sealing.py` | 封箱：校验明确方案、原子写入、稳定 `sealed_box_id`、复读 |
| `coldchain/transport.py` | 运输装载优化器（精确枚举 + 剪枝）+ 不可行报告 |
| `coldchain/repository.py` | SQLite 持久层：事务、预留表、封箱不可变触发器 |
| `coldchain/service.py` | 门面：确认/撤销/发车/更换/追溯，统一事务 + 版本检验 |

## 装箱定序（三级）

1. **最少箱数**；2. **箱体总面积最小**；3. 规范方案键字典序最小。

### 规范化方式 `coldchain-norm-v1`（随每个方案/封箱保存）

* 箱内件按 `unit_id` 升序；
* 每箱坐标取**字典序最小**可行放置向量 `((x,y,rotated), …)`（按 `unit_id`
  序排列；`rotated ∈ {0,1}`），由 `geometry.find_canonical_placement` 计算；
* 箱记录 = `(箱型ID, (件号…), (坐标…))`；方案键 = 箱记录升序元组，方案间按
  字典序比较；
* `plan_id = "PLN-" + sha256(canonical_json)[:16]`；
  `sealed_box_id = "SBX-" + sha256(box_canonical_json)[:16]`（内容哈希 →
  同一内容永远同一 ID，复读幂等）。

## 封箱

* 按**明确方案**封箱：重新校验版本、每件恰好一次、温区一致且箱型允许、
  坐标非负整数、界内不重叠、毛重（含空箱重）≤ 最大总重。
* **原子**：一个方案的全部箱在同一事务写入，任何失败不留部分封箱状态。
* **不可变**：数据库触发器拒绝 `sealed_boxes` 的 UPDATE/DELETE；每件快照
  尺寸/重量。修改商品尺寸 → 版本递增 → 旧方案变陈旧（拒绝再封），只能
  重新优化生成新方案；旧封箱内容不变。

## 运输装载

* 输入：已封箱 + 每箱目的门店；班次含允许温区、总载重、最大箱数、
  固定出车费、每停靠费。
* 箱不可拆、不可复制到两车、承运端不换装（运输层只引用 `sealed_box_id`）。
* 一车可运多门店；费用 = 固定出车费 + 不同门店数 × 停靠费。
* 全部箱必须装运：**最小总费用 → 最少出车数 → 按箱ID排序的班次ID向量**
  字典序最小。
* 装载计划直接读取封箱**毛重**（已含空箱重）。
* 不可行时返回结构化报告：每箱一条（不省略任何箱）+ 未满足约束列表。

## 并发与一致性

* 全部共享状态在单个 SQLite（WAL）中，**不是只有内存集合**。
* 多行写入都在 `BEGIN IMMEDIATE` 事务内（统一事务/可恢复提交）：要么整体
  提交，要么整体回滚。
* 确认计划 = 原子预留全部箱 + 全部班次；预留表主键是唯一硬约束——两个
  客户同时确认重叠计划，只有一个提交成功，失败方回滚、不占任何车/箱。
* 运输计划带 `version`，确认/撤销/发车/更换都需期望版本（乐观并发）。
* 撤销未发车计划释放其预留；已发车不可撤销（预留作为历史事实保留）。
* 更换为另一合法装箱产品：单事务内释放旧预留、旧计划置 REPLACED、
  插入已确认的新计划并预留——箱数/毛重变化自然传入；旧封箱与已发车
  事实保持。

## 运行

```bash
python3 -m pytest tests/ -q     # 51 个测试
python3 scripts/demo.py         # 端到端演示（8件/3箱型/6封箱/4班次）
```

测试含**独立枚举对拍**：`tests/conftest.py` 用独立实现的朴素枚举核对
装箱最优性（箱数、总面积）、每件恰好一次、箱重，以及分车最优性
（总费用、出车数、班次向量）；另含题面要求的五个场景案例（面积够却形状
放不下、旋转才可装、温区冲突、空箱重导致超载、两计划争同箱）。
